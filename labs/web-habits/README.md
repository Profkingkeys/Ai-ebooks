# A tiny HTML, CSS and JavaScript lab

Open `index.html` directly in a browser. No server or account is required.

Choose each option, confirm the result is explained, verify that completed choices are disabled, and use Try again. Navigate with Tab and Enter. Read the small transition function separately from the DOM updates.

Extension: extract the transition into a module and add a Node test for repeated actions. Then compare this tiny exercise with the complete [KidSim campaign](https://github.com/Profkingkeys/Kid-Simulation).

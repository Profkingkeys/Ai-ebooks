# Contributing

This project welcomes reviewers and contributors who can improve evidence, engineering accuracy, explanations, diagrams, labs, and accessibility.

## Pull request checklist

1. Identify the chapter and reader problem.
2. Separate established fact, interpretation, and forecast.
3. Prefer primary sources and include dates for unstable claims.
4. Add or update a diagram when it clarifies system relationships.
5. Preserve professional boundaries in medicine, pharmacy, law, finance, and security.
6. Run `npm test`.
7. State your review perspective and any conflict of interest.

Do not use invented citations, fabricated metrics, copied proprietary text, or AI-generated filler.

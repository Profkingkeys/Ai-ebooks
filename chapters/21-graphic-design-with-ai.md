# 21 · Professional Graphic Design with AI: Make the Message Easy to See

**The image looks expensive. The date is unreadable, the logo is distorted, and nobody knows what to do next. That is not a finished design.**

Professional design serves a communication task. AI can help explore visual directions, generate permitted raster assets and critique alternatives, while typography, layout, accuracy and delivery remain deliberate work. A good design brief is often more valuable than a longer image prompt.

## Setup and model choice

Choose a vector/layout editor for precise text and shapes, plus an image-generation tool only when the project needs raster imagery. Define output size, audience, viewing distance, platform, print or screen requirements, brand assets and rights. Keep an editable source file separate from exported images.

Use a text model to improve the brief, a vision model to critique hierarchy and an image model for appropriate illustrative assets. Do not generate a technical chart, medicine label or exact UI as a single image and assume its text is correct. Build exact information in editable layers. [W3C accessibility tutorials](https://www.w3.org/WAI/tutorials/) offer practical guidance for accessible web content and images.

## Work a complete example

Design a poster for a fictional student coding workshop. Its primary message is the topic; secondary information is date, time, venue and registration. Write those facts before choosing colors. Sketch three layouts with different emphasis. Select one based on readability at phone size, not only on how impressive it looks zoomed in.

Use a restrained type system: a clear heading style, a readable body style and consistent spacing. Align related information. Group by meaning, and create enough contrast between text and background. A dark photographic area may require an overlay or a separate text panel. Check the actual exported result, because compression and scaling can change legibility.

| Decision | Practical check | Common repair |
|---|---|---|
| Hierarchy | What do you notice first? | Reduce competing headings |
| Typography | Can the details be read on a phone? | Increase size and line spacing |
| Color | Is meaning available without color alone? | Add labels or shapes |
| Imagery | Does it clarify the topic? | Remove decorative clutter |
| Export | Is the file suitable for its destination? | Use correct dimensions and format |

## Give AI a constrained critique

Prompt: “Review this workshop poster for hierarchy, readability, alignment, spacing and accessibility. Identify the three most important improvements. Do not invent new event details or redesign the logo. Explain how each change helps the audience.” A critique is useful only if you inspect the actual issue and decide whether the recommendation fits the brief.

For image creation, describe composition, lighting, subject and negative space. Keep event text out of the generated background; typeset it accurately afterward. Avoid unauthorized likenesses, brand confusion and copied creative identities. Maintain an asset ledger with source, license and any required attribution.

## Practical project and troubleshooting

Deliver a phone-sized social graphic, a larger poster version and an editable source. Test the smallest version first. Ask a reader to identify the event, date and action within a few seconds, then observe where they struggle. Write alt text describing the useful information, and provide the same details in accessible text alongside the image.

If the result feels busy, remove elements before adding effects. If generated text is misspelled, replace it with real typography. If print colors shift, discuss the printer's required color profile and proofing process rather than trusting a screen preview. If a logo becomes blurry, use an authorized vector original.

The outcome is a coherent visual system with accurate information and reusable components. This skill can support health education, public-service communication, product launches and scientific outreach. AI expands exploration; design judgment makes the result usable.

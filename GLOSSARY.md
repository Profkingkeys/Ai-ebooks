# Glossary

**Agent**  
Software that uses a model to choose or sequence actions toward an objective. Agency comes from the surrounding loop and permissions, not from a mystical property of the model.

**Embedding**  
A numeric representation designed so useful relationships can be measured geometrically.

**Evaluation**  
A defined method for measuring system behavior against cases, criteria, or outcomes. A demo is not an evaluation.

**Foundation model**  
A broadly trained model adapted or prompted for many downstream tasks.

**Grounding**  
Connecting generation to supplied evidence, state, or tools. Grounding can reduce unsupported output but does not guarantee truth.

**Human-in-the-loop**  
A workflow in which a person meaningfully reviews, approves, corrects, or owns a decision. A decorative approval button is not meaningful oversight.

**Prompt injection**  
An attempt to make untrusted content behave like privileged instructions inside an AI system.

**Retrieval-augmented generation (RAG)**  
A pattern that retrieves external material and places it in model context before generation.

**Tool calling**  
A structured request from a model for application code to invoke a defined capability.

**Trust boundary**  
A place where data, identity, control, or authority crosses between components with different assumptions.
